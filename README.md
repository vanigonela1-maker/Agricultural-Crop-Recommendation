\# 🌱 Agricultural Crop Recommendation System Using Machine Learning



\## 📌 Project Overview



The Agricultural Crop Recommendation System is a machine learning-based web application that recommends a suitable crop based on soil and environmental conditions.



The system uses soil nutrients and weather-related parameters as input and predicts the most suitable crop using a Random Forest Classification model.



\## 🌾 Input Parameters



\- Nitrogen (N)

\- Phosphorus (P)

\- Potassium (K)

\- Temperature

\- Humidity

\- Soil pH

\- Rainfall



\## 🤖 Machine Learning Model



The project uses a Random Forest Classifier trained on an agricultural crop recommendation dataset.



The model achieved approximately \*\*99% accuracy\*\* on the test data.
